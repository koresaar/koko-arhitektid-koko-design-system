# KOKO design system

Ühine alus kõigile KOKO arhitektid töötajatele ja projektidele: esitlused, A4 dokumendid, plakatid, skeemid ja visuaalid.

- `SKILL.md` – KOKO esitlussüsteemi reeglid (CVI), v9 · 10.10.2026. Claude'i skill.
- `tokens.json` – värvid, tüpograafia ja ruudustik masinloetavalt.
- `design-system-usage.md` – kasutusreeglid.

Uuenda versiooni ja kuupäeva igal muudatusel; uusim fail võidab. Logofailid (`KOKO-logo_black.svg`, `KOKO-logo_white.svg`) tuleb lisada kausta `logos/`.
